PROFESSIONAL CERTIFICATE TEMPLATE UPDATE

- A4 double-border professional certificate layout.
- State/UT heading changes from the selected certificate state.
- English + selected state local-language certificate title/data.
- Birth certificate uses Form 5-style structure.
- Death certificate uses the same professional state-aware structure.
- Hospital / Local Body name and available authority metadata are loaded from Supabase.
