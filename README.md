# All India Birth & Death Certificate Admin System

## Point 1 — GitHub Pages-ready project foundation

This ZIP contains the initial frontend/file structure required by Point 1.

### Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this ZIP to the repository root.
3. Commit the files.
4. Open repository Settings → Pages.
5. Select deployment from the main branch/root as appropriate.
6. After Pages publishes, open the generated GitHub Pages URL.

### Important
Point 2 (Supabase database/storage/auth), Point 3 (complete admin functionality),
Point 4 (certificate workflows/PDF/QR), and Point 5 (All India data/languages/templates)
are not falsely marked complete in this Point 1 package.

Development/testing certificates must be identified as SAMPLE / UNOFFICIAL until
an authorized government integration is available.
